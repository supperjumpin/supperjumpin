Research notes used for these riffs

  • Components V2: Discord now supports richer message layouts: containers, sections, media galleries, thumbnails, files, buttons, selects, and file upload in modals.
  • Activities: Discord Activities are iframe web apps using the Embedded App SDK, built for social/multiplayer experiences on desktop, mobile, and web.
  • Best-in-class references: Midjourney for public artifact streams, Starboard bots for emergent highlights, event bots for RSVP/reminder ceremony, and Discord Activities case studies for shared play surfaces.
  • Round 3 synthesis: Native components excel at commitment and status because they stay in the chat stream with low friction. Activities excel at the reveal because they provide synchronized shared state, rich layout, live reactions, and recap composition.
  • Graduated experience design: The round can graduate users from low-friction native entry to high-spectacle shared reveal, with chat fallback paths for users who do not or cannot open the Activity.
